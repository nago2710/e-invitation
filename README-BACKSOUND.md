# Panduan Download Backsound Wedding

## 🎵 Cara Download dan Install Backsound

### Rekomendasi Backsound Wedding:

**Pilihan 1: YouTube Audio Library (Gratis)**
1. Buka: https://studio.youtube.com/channel/UC/music
2. Cari: "wedding romantic instrumental"
3. Download format MP3
4. Rename menjadi: `wedding-music.mp3`

**Pilihan 2: Pixabay (Gratis, No Copyright)**
1. Buka: https://pixabay.com/music/search/wedding/
2. Cari musik dengan keyword: "romantic", "wedding", "love"
3. Rekomendasi: "Beautiful Wedding" atau "Romantic Piano"
4. Download MP3
5. Rename menjadi: `wedding-music.mp3`

**Pilihan 3: Bensound (Gratis dengan Credit)**
1. Buka: https://www.bensound.com/royalty-free-music/track/romantic-piano
2. Download: "Romantic" atau "Sweet"
3. Rename menjadi: `wedding-music.mp3`

**Pilihan 4: Free Music Archive**
1. Buka: https://freemusicarchive.org/
2. Search: "wedding instrumental"
3. Download format MP3
4. Rename menjadi: `wedding-music.mp3`

### 📁 Cara Install:

1. **Download salah satu backsound di atas**
2. **Rename file menjadi**: `wedding-music.mp3`
3. **Letakkan file di folder yang sama dengan**:
   - index.html
   - style.css
   - script.js

### Struktur Folder Akhir:
```
e-invitation/
├── index.html
├── style.css
├── script.js
└── wedding-music.mp3  ← Letakkan di sini!
```

### ✅ Alternatif (Jika tidak ada file musik):
Website tetap akan berjalan normal tanpa musik. Musik akan otomatis diplay jika file `wedding-music.mp3` tersedia.

## 🎨 Fitur Animasi Amplop Sudah Aktif!

### Cara Kerja:
1. Saat buka website, muncul amplop cantik
2. **Klik/Tap amplop** untuk membuka
3. Animasi amplop terbuka smooth seperti di TikTok
4. Letter/surat keluar dari amplop
5. Transisi ke halaman undangan
6. Musik otomatis play (jika file ada)

### Tips:
- Gunakan musik instrumental yang tenang dan romantis
- Durasi ideal: 2-4 menit (akan loop otomatis)
- Format: MP3
- Size: Max 5MB untuk loading cepat
